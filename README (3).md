# CodeAlpha_FlashcardQuizApp

Task 1 – Flashcard Quiz App (CodeAlpha App Development Internship)

A simple, clean flashcard app built with HTML, CSS and JavaScript (no libraries).

## Features
- Question on the front, answer revealed with the **Show Answer** button
- **Next / Previous** navigation (also ← → keys, Space to flip)
- **Add, edit and delete** flashcards
- Progress bar and card counter
- Cards are saved in the browser (localStorage), so they persist after refresh
- Responsive layout with automatic light/dark mode

## Run
Open `index.html` in any browser. No installation needed.

## Host free on GitHub Pages
Repo → Settings → Pages → Branch: `main` / root → Save.
